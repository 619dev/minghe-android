# Minghe UI direction

Use [Wise in the Awesome DESIGN.md catalog](https://getdesign.md/wise/design-md) as a visual reference. Its green accent and simple hierarchy suit a phone client that needs one clearly identifiable primary action on each screen.

- Preserve the Minghe icon and name. Use Minghe’s green for the call and answer buttons, and reserve red for ending or declining a call.
- Keep the dial pad in three columns. On narrow windows, stack call history below it. On wide windows, put history beside it. Each history row shows the extension, direction, result and time.
- Provide light, dark and system appearance choices. Use the same layout and action hierarchy in both palettes, account for system insets, and maintain 48-pixel touch targets.
- Keep account setup to server, extension, password and one primary action. Put transport, certificate and encryption controls under advanced settings.
- Use system fonts, generous touch targets and labels that can wrap in all eight languages. Pair state colors with text and maintain readable contrast.
