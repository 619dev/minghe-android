# Changelog

## v1.0.3

- Enabled R8 for Android release builds, with keep rules for Linphone JNI bindings.

- Added light, dark, and system appearance modes with matching Android system bars.
- Adapted the phone layout to narrow and wide windows, including landscape and foldable-size viewports.
- Added eight linked README translations and localized F-Droid listing text.

- Added the Minghe launcher icon, system language defaults and an About screen with the AGPL v3.0 license.
- Added a dial pad, call history and an optional saved SIP password.
- Added discovery of self-signed server certificates with SHA-256 fingerprint confirmation.
- Updated SIP routing and SDES-SRTP negotiation for Minghe servers.
- Removed SIP messaging. This release focuses on voice calls.
