# Minghe для Android

[简体中文](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [한국어](README.ko.md) · [Русский](README.ru.md) · [Français](README.fr.md) · [Español](README.es.md) · [Deutsch](README.de.md)

Minghe — клиент голосовой связи SIP для собственного сервера Minghe. Интерфейс на React и TypeScript обращается к нативному сервису Linphone через Capacitor. По умолчанию используется системный язык. Доступно восемь языков.

## Подключение и вызовы

1. В разделе **Аккаунт** введите IP-адрес или имя сервера, внутренний номер и пароль SIP, затем подключитесь. По умолчанию используются TLS 5061, SHA-256 Digest и SDES-SRTP. Разрешайте MD5 только по требованию сервера. Для ретрансляции ZRTP выберите ZRTP в дополнительных настройках.
2. Наберите внутренний номер собеседника. В журнале видны направление, время и результат вызова. Нажатие на запись подставляет номер. Чтобы ответить, откройте приложение из уведомления. Отклонить вызов можно из уведомления.
3. При вызове ZRTP сверьте код SAS голосом. В режиме SDES-SRTP сервер расшифровывает и повторно шифрует медиапоток.

При первом подключении к серверу с самоподписанным сертификатом приложение получает сертификат и показывает отпечаток SHA-256. Перед подтверждением сверьте его с отпечатком от администратора. В дополнительных настройках также можно вставить доверенный PEM. После замены сертификата удалите старый и проверьте новый. При использовании Docker Compose выполните первую команду на сервере и сохраните открытый PEM в `server.crt` для второй команды.

```sh
docker compose exec -T minghe cat /app/certs/server.crt
openssl x509 -in server.crt -noout -fingerprint -sha256
```

Сохранение пароля включено по умолчанию и защищено Android Keystore. Если отключить его, после завершения процесса пароль нужно ввести снова. Разрешите уведомления, чтобы служба принимала вызовы при закрытом интерфейсе. Отключение от сети в приложении останавливает SIP-регистрацию. Энергосбережение Android может прервать соединение.

## Оформление и расположение элементов

В разделе **О приложении → Оформление** выберите системную, светлую или тёмную тему. Приложение запоминает выбор и обновляет системные панели Android. В узком окне клавиатура и журнал расположены друг под другом, а в широком — рядом. Интерфейс учитывает вырезы экрана и системные области жестов.

## Сборка из исходников

Установите JDK 21, Node.js 22.12 или более новую поддерживаемую LTS, Android SDK Platform 31 и 36, Build Tools 36.0.0 и NDK 27.0.12077973. Для Linphone также нужны Git, CMake, Make, Python 3, Pystache, six, Doxygen, Meson, NASM, Yasm и pkg-config. Укажите `ANDROID_HOME` и примите лицензии SDK.

```sh
npm ci
npm run build
scripts/build-linphone.sh
cd android
./gradlew assembleDebug
```

Отладочный APK находится в `android/app/build/outputs/apk/debug/app-debug.apk`. Неподписанный релиз собирается командой `./gradlew :app:assembleRelease`. Скрипт собирает Linphone 5.4.129 из исходников с удалённой интеграцией Firebase. По умолчанию собираются arm64, armv7 и x86_64. Для одной архитектуры используйте `ANDROID_ARCHS=arm64`.

## Проверка релиза

На двух устройствах проверьте SIP-регистрацию, звонки при блокировке экрана, двусторонний звук, оба режима шифрования и сверку SAS. Проверьте смену сети, восстановление после перезагрузки и ручное отключение.
